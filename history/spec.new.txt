я собираюсь сделать форк от ветки cpython 3.15

назвать это языком eelang. Потому что исходные файлы будут иметь расширение *.eel

В общем, синтаксис останется питоновским. но расширится за счёт замены = на паттерн матчинг

основные фичи

1) расширяем оператор match

он становится возможен без аргумента
старый синтаксис остается валидным

match:
    case Point(x, y) = p:
        "logic here"

это валидный синтаксис. В левой части может быть все что позволяет оператор match..case, включая условия if

Также (и это - отличие от синтаксиса case) может быть несколько выражений с = через запятую:

match:
    case Point(x, y) = p, mode = 'special' if x > y:
        "some logic"
    else:
        "other logic"



2) match становится деструктивным

Если не сматчилось ничего, должен быть MatchError

Чтобы гарантировать отсутствие ошибки, нужно добавлять блок else

3)
multiple dispatch функций

match def myfun(p: Point):
    case Point(x, y) = p if x > y:
        "..."

синтаксис case ровно такой же как и у оператора match..case

4) сокращенная версия match с одним case

match Point(x, y) = p, my_var = list() if x > y
