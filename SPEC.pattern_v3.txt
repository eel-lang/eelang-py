
делаем фичу c паттернами меньше по объёму

в v2 только смотрим/консультируемся, начинаем с чистого листа от ветки 3.15 (папка cpython-3.15-latest)

match оставляем ровно таким же, как он есть в питоне (то есть, он остается не деструктивным)

вместо

match x=1, int()=y if x<y

делаем

assert x=1, int()=y if x<y

фича match def остается и работает так же, как у нас

match def f(x):
    case x = 1:
        ...

    else:
        ...
